# Guard-cell-model

A finite element model of guard cell with subsidiary cell.

---

## Overview

This repository contains a finite element analysis model of a guard cell with subsidiary cell, developed in Abaqus to study the mechanical behavior of the guard cell–subsidiary cell complex, following the work of Zhang et al. (https://doi.org/10.1038/s41477-025-02194-4) and Durney et al. (https://doi.org/10.1016/j.cub.2023.05.051). It includes an Abaqus input file and an Excel file containing the model parameters.
 
---

## Method

1. **Morphological parameters 
   - SEM and TEM were used to obtain the thickness parameters of different parts of the guard cell wall.
  
2. **Material properties
   - Nanoindentation was used to measure the Young's modulus of the guard cell wall.
   
3. **Finite element modeling
   - A 3D model was constructed in Abaqus based on SEM and TEM images.
   - The measured Young's modulus was assigned to the model as the material parameter.
  
4. **Simulation 
   - Finite element simulations were performed in Abaqus.
